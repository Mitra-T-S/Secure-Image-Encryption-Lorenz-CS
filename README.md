# Secure Image Encryption Using Compressed Sensing and Lorenz Chaotic Maps

## Overview

This project presents a secure image encryption framework that combines image compression, transform-domain sparsification, compressed sensing concepts, and chaos-based cryptography. The system utilizes SHA-256 seeded Lorenz chaotic sequences, Arnold scrambling, and chained XOR diffusion to provide strong image security while maintaining efficient data representation.

The encryption pipeline transforms an input image into a compressed representation, applies chaotic permutation and diffusion, and evaluates security using standard metrics such as NPCR, UACI, histogram analysis, and correlation analysis.

---

## Features

- SHA-256 based secret key generation
- Lorenz chaotic sequence generation using RK4 integration
- SAE-inspired image compression placeholder
- Discrete Cosine Transform (DCT) based sparsification
- Compressed Sensing (CS) measurement generation
- Arnold Transform based pixel scrambling
- Chained XOR diffusion encryption
- Automatic UACI optimization
- Histogram analysis
- Correlation analysis
- NPCR and UACI security evaluation
- Image decryption and reconstruction
